# Exergism v0.1.0

First canonical public release of the **Metafísica emergentista de la liberación (Exergism)**.

This release establishes:

- the 14-domain canonical philosophical corpus in schema v2;
- the four-book architecture;
- the recovered formal exergic-analysis system;
- preserved applied-analysis examples;
- a reproducible generated OWL projection;
- explicit corpus/tooling licensing;
- canonical-boundary and anti-capture governance rules; and
- cryptographically inventoried release artifacts.

The release intentionally preserves and documents unresolved formal ambiguities rather than silently changing the recovered model. In particular, the transition `a1..a5` weights total 0.90 and macroevent parameters `z1`/`z2` remain unbound pending explicit future review.

This is a `0.x` release: canonical and auditable, but not a claim that the philosophical system or formal model is complete or final.
