# Applied exergic-analysis examples

These directories preserve applied-analysis artifacts recovered with the
pre-canonical Exergism corpus.

- `iran/` contains CSV datasets plus generated visualizations.
- `toma-de-kabul/` contains generated visualizations from the Kabul case.

They are retained because they document how the formal exergic model was used
in practice. The recovered corpus does not contain all source scripts or raw
inputs needed to regenerate every visualization, so these directories MUST NOT
be described as fully reproducible analytical pipelines.

Future examples should include source data, transformation/analysis code,
parameter profiles and generation instructions sufficient for deterministic or
explicitly qualified reproduction.
